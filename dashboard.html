Supabase Database Tables Setup (SQL)

Copy and run this SQL script in your Supabase Dashboard → SQL Editor to create the cakes and orders tables: 

-- ========================================================
-- DÉLICE & CO. — COMPLETE SUPABASE DATABASE SETUP SCRIPT
-- Copy and paste into Supabase Dashboard -> SQL Editor -> Click RUN
-- ========================================================

-- 1. Create Cakes Catalog Table
create table if not exists public.cakes (
  id text primary key,
  name text not null,
  category text not null,
  price numeric not null,
  image text,
  flavor text,
  dietary text,
  slices text,
  description text,
  lead_time text default 'Same Day (2 Hours)',
  in_stock boolean default true,
  created_at timestamptz default now()
);

-- 2. Create Orders Table
create table if not exists public.orders (
  id text primary key,
  customer jsonb not null default '{}'::jsonb,
  items jsonb not null default '[]'::jsonb,
  dietary text,
  cake_message text,
  delivery_date text,
  delivery_slot text,
  subtotal numeric default 0,
  delivery_fee numeric default 0,
  total numeric default 0,
  payment_method text default 'RAZORPAY',
  status text default 'pending',
  created_at timestamptz default now()
);

-- 3. Grant schema and table permissions with Row Level Security (RLS)
grant usage on schema public to anon, authenticated, service_role;
grant select on public.products, public.categories, public.product_variants, public.delivery_slots to anon, authenticated;
grant all on all tables in schema public to service_role;

-- 4. Enable Row Level Security (RLS) & Secure Policies
alter table public.orders enable row level security;
-- See database/FIX_SUPABASE_SECURITY_RLS.sql for production security policies.

Fix Supabase Table Permissions

Allow website orders into your PostgreSQL database

Why did Supabase show 0 entries?
PostgreSQL Row-Level Security (RLS) is enabled by default in Supabase, which blocks public customer inserts. Running this 1-click SQL script permanently allows orders to write to Supabase! 
ALTER TABLE public.orders DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.order_items DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.payments DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.custom_cake_orders DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.delivery_slots DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.coupons DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.products DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.product_variants DISABLE ROW LEVEL SECURITY;
